# Nerdcore Community Platform

## Overview
A community-driven platform for Nerdcore artists and events.

This project will:
- Map Nerdcore artists by location and region
- Display events across the country
- Integrate with Discord for querying artists and events
- Provide a moderated submission system

## Goals
- Single source of truth for artist + event data
- Website integration (map + calendar)
- Discord bot integration
- Built and hosted in AWS

## Tech Stack
- **Frontend:** SvelteKit + TypeScript (Cloudflare Pages)
- **API:** AWS Lambda + API Gateway
- **Database:** PostgreSQL on AWS RDS
- **Map:** Mapbox GL JS
- **Calendar:** FullCalendar
- **Bot:** Discord slash commands (calls same API)
